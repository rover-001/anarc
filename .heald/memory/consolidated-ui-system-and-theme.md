# Consolidated: UI System & Theme

Consolidated architectural decisions, system invariants, and implementation patterns.

## Core System Decisions & Invariants

- **Modularize shield, plugin distribution/wasm_host, context_menus/sidebar, and agent act parse/exec**: Split 7 monolithic files (>870 lines each) into focused submodules with shared helpers and zero behavioral/UI changes: src/shield/, src/plugin/distribution/, src/plugin/wasm_host/, src/app/render/context_menus/, src/app/render/sidebar/, src/agent/act/parse/, src/agent/act/exec/.
- **Plugins settings page uses 4-column grid layout**: Updated src/ui/plugin_manager.rs to render plugin cards in a 4-column grid (.grid().grid_cols(4).gap_3()) with card headers (name, kind, version, toggle/Required badge), wrapped text, and bottom action buttons (Open/Remove) while preserving all existing click handlers and debug selectors.
- **Smooth favicon and logo rendering via RGSS minification and 48px Triangle pre-downscale**: Fixed aliased/overly-sharp favicons and Anarc logo caused by single-tap bilinear sampling of un-mipmapped atlas textures during heavy downscaling (96px->20px logo, 128-512px->14px favicons) and Lanczos3 ringing. Added 4-tap rotated-grid supersampling (RGSS) in fs_poly_sprite (vendor/gpui-pre-wgpu/src/shaders.wgsl) when texel footprint > 1.25, downscaled anarc_logo to 48x48 with FilterType::Triangle in src/ui/visual.rs, and unified favicon RenderImage creation via render_image_from_rgba in src/engine/mod.rs capping uploaded favicons at 48x48 with Triangle filtering.
- **Automatic YouTube Picture-in-Picture (PiP) built-in plugin with hover controls and captions**: Added toggleable built-in plugin anarc.pip (src/pip.rs, src/plugins.rs). Injects a YouTube DOM/video bridge on page.load_end that reports playback, mute, caption toggle, and live caption text via [ANARC_CB_PIP] console messages into BrowserSharedState.pip. Switching away from a playing YouTube tab activates floating PiP (pip_tab_id), keeps the background tab in visible_ids at 384x216 so CEF OSR continues painting frames, and renders the video, live captions, and hover controls (play/pause, -10s/+10s seek, mute, CC toggle, back-to-tab, close) in src/app/render/shell/mod.rs.
- **Default CEF runtime uses proprietary-codec build for H.264 playback**: Anarc on Linux now installs a checksum-pinned CEF 156.0.26 build with proprietary_codecs=true (H.264/AAC) via tools/install-cef-codecs.sh, called by install.sh by default (--no-codecs opts out). Stock cef-dll-sys uses the Spotify minimal build where canPlayType(avc1) is empty, breaking MP4 previews in web apps. Original runtime is backed up to ~/.local/share/anarc-cef-minimal-backup. Verified canPlayType(avc1.640028)=probably and VideoDecoder avc1.640028 supported=true, plus real MP4 playback at 1920x1080.
- **Four-pane split grid and drag-to-pane split UX**: Space.split remains Option<SplitPair> for save compatibility; SplitPair gained optional third/fourth tab ids (serde default) forming a 2x2 grid. Lumen gained third/fourth WebViewports, split_ratio_y and split_resizing_horizontal. Ctrl+Shift+S grows 2 panes to 4; Ctrl+Alt+arrows cycles panes 0..3. Dropping a sidebar TabDrag on a browser pane splits/extends/replaces that pane. Kept-tile drag preview opens the after-slot by default so the hovered tile slides left; the bottom dashed row is transparent until hovered. User-visible Lumen strings and the Rust type were renamed to Anarc; plugin ids/config keys/MCP tool names kept for compatibility.
- **Anarc MCP visual browser control & tab lifecycle**: Replaced headless Python SQLite mock MCP wrapper with anarc-ctl mcp, automatically focusing and launching GUI window via omarchy-launch-or-focus. Added tab management DSL and CLI controls for pin, unpin, fav, unfav, close, new, select, and updated MCP schemas.
- **Anarc Agent Control subagent telemetry, policy confirm gate on Send, and CEF lazy tab handling**: Audited subagent browser automation in Anarc. Discovered: 1) Tabs created in Anarc are initialized lazily by CEF only when activated/rendered in GPUI, causing 'tab not found' if queried before UI render. 2) PolicyConfig hardcodes 'send' in confirm_intents, triggering 'needs_confirm' on chat apps with a 'Send' button. 3) LLM subagent crashed on step 145 when calling read_file on binary PNG screenshot causing API code 400. 4) Successfully captured full execution telemetry (63 tool calls, 2,463,527 total tokens, 252s elapsed time).
- **Eliminate OSR scrolling judder with dirty rect reuse, zero wake latency, and 1:1 input fidelity**: 1. Implemented persistent cached_buffer in LumenRenderHandler with copy_dirty_rects, eliminating full 8.3MB frame reallocations per paint. 2. Removed cx.on_next_frame deferral from the UI update loop, triggering immediate repaint without 2-frame latency. 3. Retained 2-frame depth window in retired_images before dropping to prevent WGPU atlas churn. 4. Scaled wheel lines by 100px * device scale factor, set WHEEL_SCROLL_SCALE to 1.0, dispatched precision touch deltas directly for zero input lag, and added smooth momentum fling on release. 5. Driven send_external_begin_frame from Lumen::render aligned with GPUI vsync at 144Hz.
- **Web view container enforces size_full layout and suppresses trailing pinch moves**: Root cause of the floating 50% card shrinkage on trackpad pinch-in and release: WebViewport render set explicit dimensions w(width * pinch_factor).h(height * pinch_factor) and top(pinch_offset.1).left(pinch_offset.0) on the inner container with CARD_RADIUS. When returning to natural scale (or unzoomed), any factor <= 1.0 or trailing TouchPhase::Moved event recreated the preview with factor < 1.0, shrinking the viewport into a 50% floating card with rounded corners exposing window background. Fix: 1) Made current container strictly size_full() whenever pinch_factor <= 1.0, and clamped offsets with min(0.0) so content never pulls away from viewport edges; 2) Added pinch_active tracking to ignore trailing TouchPhase::Moved events that arrive after Ended/Cancelled; 3) Made transition and crossfade containers size_full().
- **Pinch preview enforces floor factor of 1.0 to prevent card shrinkage**: Render for WebViewport previously calculated factor = scale / base_scale, which produced factor < 1.0 (e.g. 0.5) when pinching in or returning from high zoom levels. This caused GPUI to shrink the container to width*factor and height*factor, rendering a small floating card inside the viewport and exposing window background. Clamped factor to 1.0 (pinch_factor = 1.0, pinch_offset = (0,0) whenever factor <= 1.0 + 1e-4) so the webpage container can never shrink below full viewport size.
- **Window disables GPUI inactive frame interval so background pages keep full cadence**: GPUI caps unfocused/inactive windows at ~30 fps via WindowOptions::inactive_frame_interval (33_333 us, only bypassed by sustained high-rate input) and gpui-linux drops the periodic refresh loop once the X11 window is not visible. A browser that plays video or animates in the background looked laggy next to the focused window. src/main.rs now opens the window with inactive_frame_interval: None. Rendering stays demand-driven (dirty frames only), so idle cost is unchanged; release cadence for an animating page went from 39-100 to 77-119 root UI renders/s at OSR paints/s=144.
- **Physics-based motion system (springs) for all UI animations**: Replaced duration+easing animations with Apple (response, dampingFraction) springs in src/ui/motion.rs. SpringSpec converts (response, zeta) into gpui SpringConfig (k=(2pi/response)^2, c=4pi*zeta/response, m=1) and exposes config(), settle_time(), duration(), progress(elapsed), easing(), animation(), enter(), between(), to(). Presets (response, zeta): pop 0.26/0.75, popover 0.28/0.85, toggle 0.26/0.80, sheet 0.38/0.85, content 0.33/0.90, space_switch 0.40/0.90, sidebar 0.40/0.90, row_enter 0.30/0.85, row_exit 0.22/1.0, theme 0.28/1.0, pinch_settle 0.18/1.0. Element entrances/exits use with_spring (interruptible, state per element id); Instant-driven interpolations (theme colors, sidebar width, space switch, browser frame crossfade) use spec.progress()/spec.animation() so the guard/timer duration always equals the animation duration. ANARC_REDUCED_MOTION maps to cx.set_reduce_motion in main.rs so with_spring/with_animation snap. Pinch release within 1.05 of 100% snaps to 1.0 via spring ticker (8 ms) driving Engine::pinch_zoom; Engine::page_scale reads state. Scroll fling/inertia intentionally not added (compositor kinetic scroll).
- **Fix address bar search submission lifecycle and pending browser load cancellation**: 1. Stored initial_url on BrowserSharedState during browser creation so that take_created_browsers only triggers frame.load_url if pending_url diverged from initial_url while pending; this eliminates premature ERR_ABORTED cancellation on newly opened or discarded tabs. 2. Updated navigate to accept window: Option<&mut Window> and immediately transfer focus to browser_focus_handle and the CEF tab via focus_browser on Enter keydown or autocomplete suggestion click, ensuring address_focused resets cleanly and user keystrokes route to the page.
- **Unlock full display refresh rate up to 240Hz for hardware accelerated rendering**: Raised OSR frame rate cap from 60 to 240 fps on systems with hardware GPU acceleration, allowing Anarc to automatically match 144Hz and high-refresh displays while keeping software-only rendering clamped to 60 fps to preserve CPU on headless or non-GPU environments.
- **Fix pinch zoom rubber-band bounce and address bar search submission**: 1. Replaced wheel event injection during trackpad pinch zoom with instant programmatic window.scrollBy via Blink DevTools, eliminating overscroll spring bounce animations and inner element scroll hijacking while maintaining cursor anchoring. 2. Fixed address bar Enter key event handling so that entering queries navigates immediately regardless of whether autocomplete suggestions are open or selected. 3. Added pending browser URL resolution in CEF runtime to guarantee navigations on newly created or pending tabs load reliably.
- **Eliminate panning, zooming, and scrolling lag on high refresh displays**: 1. Raised OSR_MAX_FRAME_RATE from 60 to 240 fps, allowing CEF offscreen rendering and GPUI fallback pacing to match native monitor refresh rates (such as 144Hz) without judder or 60Hz throttling. 2. Fixed pinch-to-zoom by adding immediate OSR view invalidation and UI loop wake dispatch in pinch_zoom, setting instant scroll behavior in DevTools scrollBy to bypass CSS smooth-scroll fighting, lowering PINCH_EMIT_INTERVAL to 4ms for 144Hz gesture pacing, and expanding MIN_PAGE_SCALE to 0.25 to allow zooming out. 3. Increased line scroll step multiplier from 40px to 100px to match standard Chromium mouse-wheel travel. 4. Resolved collapsible-if and negated-comparison clippy lints across tabs, browser, and clipboard modules.
- **Fix pinned tab restoration, trackpad visual zoom, and clipboard selection**: 1. Resolved pinned/favorite tab URL persistence: added pinned_title field to Tab, ensured unload_kept_tab restores tab.url and tab.title from pinned destination on unload/close, startup resets kept tabs, and sidebar/context-menu close actions use close_section_tab. 2. Trackpad pinch zoom now sends Ctrl+mouse_wheel events via pinch_wheel_delta to emulate Chromium visual viewport zoom rather than changing layout page zoom level. 3. Fixed compilation error CefStringUserfreeUtf16 by converting through CefStringUtf16::from, wired right-click context menu copy/paste, and auto-synced selected text to Wayland/X11 primary clipboard on mouseup. 4. Successfully built and installed release binary via ./install.sh.
- **Cap CEF OSR frame rate at 60 and pass button flags on mouse moves**: OSR paints cost a full-window BGRA memcpy plus a new RenderImage/atlas upload per frame, so tracking display refresh (144/240Hz) saturated memory bandwidth and stalled CEF compositing on heavy pages. frame_rate_for_refresh now clamps to OSR_MAX_FRAME_RATE=60 (ANARC_OSR_FPS overrides for benchmarks); it doubles as the UI update loop fallback cadence. Separately, CEF mouse-move events must carry the held-button bits (EVENTFLAG_LEFT_MOUSE_BUTTON=1/MIDDLE=16/RIGHT=32) in MouseEvent.modifiers or Blink sees Button::kNoButton and never starts drag selection, which is why text could not be selected/copied by click-drag; Engine::send_mouse_move takes gpui MouseMoveEvent.pressed_button and send_mouse_click passes the button on press only.
- **Shield mirrors uBlock Origin Lite; no WebExtensions in Alloy**: The built-in shield compiles the same filter sets the user has enabled in Chromium uBlock Origin Lite (EasyList, EasyPrivacy, uBlock filters, uBlock badware, Peter Lowe) plus Lumen starter rules (assets/filters, see LICENSES.md), and now runs a cosmetic stage: url_cosmetic_resources -> one injected <style> of hide selectors, executed on page.load_end via Engine::shield_cosmetic_script. urlhaus-full is intentionally not bundled (12 MB, malware not ads). Literal uBOL cannot load because CEF runs RuntimeStyle::ALLOY (no extension support); do not plan extension loading without switching to the Chrome runtime.
- **Sidebar right-click context menu and blank tab close animation fix**: Fixed sidebar canvas right-click context menu by attaching handler to root sidebar content, drop zone, and empty canvas. Prevented ghost closing tab flash when closing empty/blank tabs by skipping closing_tab state, and anchored closing tab exit animation to root sidebar coordinates instead of nested regular_tabs container.
- **Eliminate heavy site scroll and network stutter on hianime**: Diagnosed lag on heavy media/ad-heavy sites (such as hianime.at/home). Fixed 5 compounding bottlenecks: 1) Added a fast 8K-entry hash cache to ShieldState dropping adblock query overhead from 1110µs to 5.8µs (189x speedup) and preventing CEF network thread serialization on subresources; 2) Enabled Chromium hardware GPU rasterization, ignore-gpu-blocklist, zero-copy, and OOP canvas rasterization while re-enabling GPU shader disk cache; 3) Throttled OSR median edge color calculation from 144Hz to 1Hz with stride sampling; 4) Implemented subpixel scroll delta accumulator in WebViewport to prevent fractional scroll ticks from dropping to zero; 5) Removed redundant UI loop wakeups on mouse wheel dispatch.
- **Create private repo anarc and publish installation guide**: Created private GitHub repository rover-001/anarc, hardened .gitignore against secrets and caches, scanned staged code for credentials (clean), updated README.md with comprehensive installation instructions for Linux and CEF setup, and pushed main branch.
- **Rebrand browser to Anarc and polish button responsiveness**: Renamed browser from Lumen to Anarc across window title, settings, and core plugin descriptor; embedded the uploaded Anarc logo as compile-time asset in welcome view, sidebar header, and settings; fixed favorite tiles to size responsively across sidebar width with properly scaled 20px favicons; grouped plugin manager install action buttons responsively.
