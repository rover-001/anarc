# Consolidated: Social Integrations & OAuth

Consolidated architectural decisions, system invariants, and implementation patterns.

## Core System Decisions & Invariants

- **Optimized Checkmate subagent automation: 91.5% token reduction and 61.9% speedup**: Optimized cross-model subagent execution by eliminating shell and filesystem detours, batching Anarc do DSL actions, pinning to flash model, and using targeted last-element extraction. Achieved 96s execution (down from 252s, -61.9%), 10 total tool calls (down from 63, -84.1%), and 209,322 tokens (down from 2,463,527, -91.5%).
- **Multi-instance launches get CEF profile slots**: Anarc allows up to 9 concurrent windows. The installed launcher wrapper (/usr/local.. no: ~/.local/bin/anarc generated by install.sh) tries flock slots 1..9 in $XDG_RUNTIME_DIR and exports ANARC_INSTANCE_SLOT for slots 2+. paths::cef_root_dir() maps slot>=2 to <data>/cef/instance-<slot>; slot 1 keeps <data>/cef. Reason: Chromium places its process singleton + cookie/cache databases inside --user-data-dir (= CEF root_cache_path), so two processes sharing it corrupt the profile. Settings, spaces.json, history.sqlite (WAL) and favicons stay shared, matching a second browser window. Request-context profiles remain direct children of the root cache path.
- **Download handler fix and uBlock Origin integration with YouTube ad shield**: Implemented can_download=1 and on_before_download=1 in LumenDownloadHandler with UI loop wakes to enable file downloads; added active download button indicator badge and top-right download progress toast. Pre-installed uBlock Origin with YouTube ad tracking filters and client-side SPA ad-stripping scriptlet for in-stream and banner ad elimination.
- **Configure release profiles and native cpu rustflags**: Added release profile with opt-level=3, thin LTO, 1 codegen-unit, panic=abort, strip=symbols; pruned image crate default features to png,jpeg,gif,webp,ico; configured .cargo/config.toml with target-cpu=native.
